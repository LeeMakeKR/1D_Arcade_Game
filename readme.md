ws2812 line led 를 사용한 1d arcade 게임기 제작 프로젝트

게임 방식
solo

1.지렁이 게임
RGB LED로 이루어진 지렁이가 접근.
RGB 스위치로 지렁이 칼라에 맞는 스위치를 누르면 해당 LED 가 '발사' 되고 지렁이의 길이가 줄어듦
게임 난이도에 따라 지렁이 길이와 속도가 변화

추가 난이도로 지렁이도 총알을 발사. 

2. SOLO PONG
타이밍에 맞춰 스위치를 누르면 LED 공이 발사되고 반대쪽에서는 LED가 반사됨. 
타이밍이 정확할 수록 상대망이 받아치기 힘들어짐
난이도가 올라갈 수록 상대방은 잘 받아치며 공의 속도가 빨라짐

- 난이도에 따라 LED 공의 칼라가 변할 수 있음

3. line wobbler
조이스틱으로 도트 캐릭터 이동, 빨간 적·용암 지대·움직이는 장애물 회피, 흔들어서 공격. 검증된 명작 방식
- 조이스틱 필요

4. 타이밍 스톱 — 빠르게 왕복하는 LED를 목표 구간(초록 존)에서 정지시키기. 성공할수록 존이 좁아짐

5.반응속도 테스트 — 무작위 시점에 LED가 켜지면 최대한 빨리 버튼. 반응 시간을 LED 길이로 표시


회피 러너 — 플레이어 도트는 고정/이동, 접근하는 장애물을 점프(버튼)로 회피. 1D 공룡 게임

1. DUEL PONG
두 명이 대결하는 게임




회피 러너 — 플레이어 도트는 고정/이동, 접근하는 장애물을 점프(버튼)로 회피. 1D 공룡 게임
총알 지옥 (1D 슈팅) — 양방향에서 접근하는 적을 색상 맞춰 격추. 지렁이 게임의 확장판
두더지 잡기 — 라인 위 무작위 위치에 색상 점멸, 해당 색 버튼을 시간 내 타격

퍼즐/두뇌
8. Simon Says (기억력) — 색상 순서가 LED로 재생되면 순서대로 버튼 입력. 점점 길어짐
9. 1D 테트리스 / 스택 — 접근하는 블록을 타이밍 맞춰 쌓기. 어긋난 만큼 잘려나감 (Stack 게임의 1D 버전)
10. 색 합성 퍼즐 — R+G=노랑 등 색 혼합으로 목표 색 만들기
11. 금고 털기 — 회전하는 다이얼처럼 LED가 순환, 특정 위치에서 정확히 멈추기를 연속 성공
성장/전략
12. 1D 스네이크 (원조 방식) — 먹이를 먹으면 길어지는 뱀. 자기 몸이 라인을 가득 채우기 전까지 생존
13. 타워 디펜스 — 한쪽 끝이 기지, 접근하는 적 웨이브를 색상 매칭 공격으로 방어. 웨이브마다 강화
14. 낚시 — 라인 아래로 훅을 내리고, 지나가는 물고기(색 도트) 타이밍에 낚아채기
캐주얼
15. 1D 룰렛/슬롯 — 감속하며 도는 LED가 어디서 멈추나. 베팅 요소
16. 줄다리기 vs CPU — 버튼 연타로 중앙 표시등을 내 쪽으로 끌어오기
17. 폭탄 돌리기(혼자) — 점점 빨라지는 타이머 LED, 특정 조작 성공 시 시간 연장
DUEL 게임

줄다리기 (Tug of War) — 양쪽에서 버튼 연타, 경계선을 상대 진영 끝까지 밀기. 구현 최간단, 파티에서 최고 인기
반응속도 대결 — 신호 LED 점등 순간 먼저 버튼 누른 쪽 승. 페이크 신호(빨강)에 누르면 감점
1D 격투 — 각자 캐릭터 도트를 이동시키며 공격/가드/대시. 사거리와 타이밍 싸움
영역 전쟁 — 자기 색으로 LED를 칠하며 전진, 상대 색을 덮어씀. 제한시간 내 점유율 승부
스네이크 대전 — 두 마리 뱀이 같은 라인에서 먹이 경쟁, 충돌 회피
폭탄 돌리기 — 폭탄 LED가 왕복, 자기 쪽에 있을 때 타이밍 버튼으로 되돌려보냄. 폭발 시 패배 (핫포테이토)
동시 슈팅 대전 — 서로에게 총알 발사, 상대 총알은 색 맞춰 요격 가능. 지렁이 게임의 PvP화
리듬 배틀 — 같은 패턴을 동시에 플레이, 정확도 높은 쪽이 상대에게 방해 요소 전송
Simon 대전 — 번갈아 색 시퀀스에 하나씩 추가하며 따라하기, 먼저 틀린 쪽 패배
결투(서부극) — "Ready..." 후 무작위 딜레이, 신호에 먼저 쏘는 쪽 승. 3판 2선승

시스템/부가 아이디어

난이도 외 변형 요소: 아이템 드롭(속도 감소, 라인 일시 확장), 보스전(긴 지렁이+체력바), 콤보 시스템(연속 성공 시 배율)
하이스코어 표시: 게임 오버 후 LED 바 그래프로 점수 시각화, EEPROM 저장
어트랙트 모드: 대기 중 레인보우 데모 애니메이션
사운드: 피에조/DFPlayer로 타격음 추가 시 몰입감 크게 상승
입력 다양화: 버튼 외에 가속도계(흔들기 공격), 로터리 엔코더(위치 이동), 조이스틱
